# Contributing

For a bug, open an issue with the app version or commit, device and iOS version, expected behavior, and reproduction steps. Please use test accounts and remove personal details from screenshots and logs. Report vulnerabilities privately as described in [SECURITY.md](SECURITY.md).

For code changes, create a branch from `main`, follow the existing Swift conventions, and keep the pull request focused. Run the LiNGUiD scheme in Xcode and test the changed flow on a simulator. In the pull request, explain what changed and what you verified. Use a development Firebase project and keep credentials and real user data out of the diff.
